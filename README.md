# Ransomware Simulation Lab

A frontend-only cybersecurity training dashboard for demonstrating ransomware-like behavior detection, simulated containment, and recovery verification.

> **Educational simulation only.** The app uses mock data in React state. It does not access, encrypt, rename, delete, corrupt, or modify real files. It does not monitor the operating system or use a backend, database, network service, browser storage, or external API.

## Run locally

Requirements: Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`). To bind only to this computer:

```bash
pnpm dev -- --host 127.0.0.1
```

## Build

```bash
pnpm build
pnpm preview
```

The build command runs TypeScript project checks and creates a production build in `dist/`. `pnpm preview` serves that build locally.

## Using the lab

1. Choose **Simulation** from the sidebar.
2. Select **Initialize lab** to create the 25 virtual test-file records and their simulated baseline identifiers.
3. Select **Start simulation**. The lifecycle progresses through monitoring, simulated suspicious activity, detection, containment, and recovery.
4. Visit **Virtual Files**, **Detection**, **Event Logs**, and **Recovery** to inspect each part of the exercise.
5. After the lifecycle completes, open **Reports** to view the summary.

The **Pause**, **Resume**, **Stop**, and **Reset** controls affect only the current in-memory simulation. Refreshing the page resets this state.

## App sections

- **Dashboard** — status, metrics, lifecycle, activity visualization, virtual files, detection, events, and recovery summary.
- **Simulation** — lifecycle progress and operator controls.
- **Virtual Files** — mock file metadata and simulated baseline/current hash identifiers.
- **Detection** — simulated behavioral rules, activity chart, and alert state.
- **Event Logs** — events generated by the current simulation session.
- **Recovery** — simulated restoration and verification status.
- **Reports** — final simulation summary, available after a run completes.

## Safety and data notes

- File names, sizes, and hashes are fictional display data held in application state.
- Hash values are simulated identifiers; they are not computed from files and are not cryptographic integrity checks.
- Detection rules evaluate only the app's mock simulation events. No real endpoint or filesystem monitoring is present.
- All recovery and containment indicators describe simulated actions only.
